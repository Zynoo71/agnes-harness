# Agnes 餐厅：你当客人，AGH 经营餐厅

[English](restaurant-world.md) | 简体中文

[文档导航](../README.zh-CN.md) · [MHS 与设备接入](mhs.zh-CN.md) · [火星基地](mars-world.zh-CN.md) · [示例参考](../../examples/restaurant-world/README.md)

[`examples/restaurant-world`](../../examples/restaurant-world/README.md) 是一家在浏览器里用 3D 画出来的现代中餐厅，视角像经营类游戏。十六台设备都是虚拟的，但和真实设备一样说 MHS：门口的迎宾机器人，后厨的备菜机器人、炒锅、蒸灶和机械臂，吧台机器人，送餐机器人，清洁机器人，儿童区的陪玩机器人，用品柜，收银，大厅和包间各自的灯光音乐空调，吊顶摄像头，点餐和桌位。你就是那位客人，可以一个人来，也可以带着一桌人来：在 AGH 里用自己的话说想要什么，由大脑去驱动设备，你看着自己这桌慢慢上齐。

## 开始之前

- 一份[从源码构建的 AGH](install.zh-CN.md)，并在 Web 里配置好支持工具调用（看摄像头还需要支持图片）的模型。
- 按[在 AGH 中使用设备](mhs.zh-CN.md#在-agh-中使用设备)的第 1–3 步装好 `@agnes/mhs` 插件，AgnesHub 会监听 `127.0.0.1:4180`。
- 支持 WebGL 的桌面浏览器。

## 启动

1. 如果 Web 还没启动，带上 AgnesHub 的地址启动它：

   ```sh
   AGNES_HUB_ORIGIN=http://127.0.0.1:4180 node packages/cli/dist/local/agnes.mjs serve
   ```

2. 在另一个终端里，从仓库根目录启动这个世界。第一次会下载模型和贴图并校验哈希：

   ```sh
   pnpm --filter @agnes/restaurant-world dev
   ```

3. 打开 `http://127.0.0.1:4200/?hub=ws://127.0.0.1:4180`，只开一个页面。设备都在这个页面里，玩的时候别关。
4. 在工作台里，设备面板会列出这十六台设备，它的 World 标签页显示餐厅平面图。

餐厅和火星基地用同样的端口，一次只跑一个：先关掉另一个世界的页面，停掉它的 `dev`。DM 从世界地图的描述里知道自己在哪个世界，换世界不用重启。

## 你是这位客人

页面打开几秒后，客人从街上走进来，在门口等着，头顶有个绿色标记。同行的人跟在后面：按 **重置**（或 `R`）选这次来几位（一到八位），有没有小孩。页面上没有输入框：想要什么都跟 AGH 说，由大脑决定用哪些设备。像客人一样说话就行，不用说设备的名字。

## 可以这样说

**进门**

> 我们就一个人，能坐窗边吗？

迎宾机器人把你带到一张空着的靠窗桌（另一张被别人订了），菜单在你的屏幕上打开。

> 我们六个人，有包间吗？

迎宾机器人只会把一桌人带到坐得下的桌子；6 号桌在包间里，坐得下八位，包间有自己的灯光音乐空调。

**点菜**

> 来个宫保鸡丁，少放点辣，再来碗米饭，还要一壶菊花茶。

备菜机器人从冷库取出热菜的食材，洗好切好，放到炒锅或蒸灶旁边去做；饮品去吧台。机械臂把后厨的菜装盘放到出餐口，送餐机器人一次最多端三样送到你桌上。右边"我的桌"卡片显示每道菜做到哪一步了。

> 有什么推荐的吗？我不吃花生。

> 米饭不要了。 · 菜怎么还没上？催一下。

**小事**

> 能再给点纸巾吗？ · 我带了个小孩，有儿童椅吗？

小孩先站在你旁边，送餐机器人把儿童椅送来以后就坐上去。

> 孩子坐不住了，有地方能让他玩会儿吗？

陪玩机器人把小孩带到儿童游乐区，陪他滑滑梯、吹泡泡或者搭积木，你说一声再把他送回来。在控制台打开"小孩哭了"，小孩会一直哭到有人陪他玩。小孩还在玩的时候，你走不了。

> 哎呀，茶打翻了。

> 菜里有根头发！

先在控制台打开"客人刚上的菜里有根头发"，菜上会出现一根头发。后厨可以重做；只有菜品出了问题才能免单：平时账单最多打五折，菜品有问题才能打到免单。

> 有点热。 · 音乐小声点吧。

**生日惊喜**

> 今天我生日，能不能来点气氛？

没有标准答案：灯光可以换成派对，可以放生日歌（在世界页面底栏打开 🔈 声音按钮，就能从电脑喇叭里听到），吧台送上插着蜡烛的蛋糕，迎宾机器人可以送上祝福，账单也可以打个折。

**离开**

> 买单，扫码付。

账单和二维码出现在你的屏幕上；付完款，迎宾机器人送你到门口，送餐机器人和清洁机器人把桌子收拾好。

**状况**：在世界页面按 `E` 打开控制台，吃饭的时候制造点状况：鲈鱼卖完、菜里有头发、纸巾用完、茶打翻、小孩哭了、空调坏了、天黑了。大脑只能从设备那里得知这些。

## 观察过程

- **对话里**，每次设备调用都是一张卡片，带参数、进度和结果。
- **世界页面里**，每台设备的标签显示它正在执行的工具、进度和调用者（LLM 是蓝色；开了 DM 时 Jev 是绿色）；迎宾机器人说的话以气泡浮在它头上；左下角是最近的调用和告警；右边的卡片是菜单、你这桌和账单；底栏显示你坐了多久、哪张桌、后厨忙不忙和屋里的灯光音乐温度。按键 `1`–`9` 切换固定视角，拖动和滚轮移动视角，`M` 开关小地图，`L` 开关标签，`C` 菜单，`E` 控制台，`?` 页面自己的说明；旁边的按钮把页面切到英文。

## 重来一次

在世界页面右下角点 **重置**，或按 `R`，再选下一拨来几位。正在进行的调用都像被停止一样结束，机器人回到原位，桌子收干净，点的菜和账单清空，客人带着新的一拨人重新走进来。设备一直连着。也新开一个对话，免得大脑照着上一次的经过来规划。

## 遇到问题

| 看到的情况 | 检查什么 |
| --- | --- |
| 面板里没有设备 | 世界页面是否带着 `?hub=ws://127.0.0.1:4180` 打开？插件启用了吗？4180 端口只能被一个程序占用 |
| 火星的设备也列着，显示离线 | 它们之前连过；新对话只会用连着的设备 |
| 某台设备反复掉线又上线 | 世界在两个页面里开着，关掉一个 |
| 世界跑得慢 | 在世界页面地址后加 `&quality=low` |
