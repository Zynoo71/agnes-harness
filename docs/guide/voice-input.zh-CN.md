# 电脑端语音输入

[English](voice-input.md) | 简体中文

Web 工作台通过火山 Agent Plan 将麦克风音频实时转为文字。在启动 Web 服务的进程环境中设置 `AGH_ASR_API_KEY`，再正常启动 AGH。Key 不应写入仓库或浏览器配置；未设置时，服务端拒绝 ASR 连接。该通道仅接受当前本机 Web 来源，不开放手机或远程访问。

选择会话，点击麦克风图标（“语音输入”）并允许使用麦克风，即可在输入框里边说边看转写结果。录音期间输入框只读，暂不可发送。点击停止图标（“结束录音”），最终文字会追加到当前草稿，修改后手动发送。“取消录音”（×）、切换会话、AGH 连接断开或关闭页面会丢弃本次转写，保留原有草稿和附件。结束录音不会取消正在执行的任务。

录音使用 AudioWorklet，转换为 16 kHz、单声道、16 位 PCM，经 `/api/asr` 转发。服务端保管密钥，单次录音最长两分钟，每个 Web 服务最多允许两条并发连接，并限制缓冲区大小。失败时保留原草稿。音频会发送给火山，本模块不在本地保存录音。

请使用支持麦克风和 AudioWorklet 的现代电脑浏览器。首版按本机部署验证，手机端的 HTTPS 和远程鉴权另行处理。

接口依据：[Agent Plan 语音文档](https://docs.volcengine.com/docs/ark/agent-plan-personal-voice-model?lang=zh)。
